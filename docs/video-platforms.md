# Подключение YouTube и VK Видео к Art Radar

Сбор открытых авторских лент YouTube и публичных метаданных RUTUBE уже работает без ключей. Подключения ниже добавляют подтверждённый хронометраж, ограниченный поиск YouTube и чтение каналов VK Видео. Все команды диагностики работают без публикации.

## YouTube Data API v3

1. Откройте Google Cloud Console, создайте проект или выберите существующий. На странице **YouTube Data API v3** нажмите **Enable**. [Страница API](https://console.cloud.google.com/apis/library/youtube.googleapis.com)
2. Перейдите в **APIs & Services → Credentials → Create credentials → API key**. Откройте созданный ключ и в **API restrictions** выберите только **YouTube Data API v3**. Для общедоступных метаданных достаточно этого ключа. [Авторизация YouTube Data API](https://developers.google.com/youtube/data/guides/authentication)
3. В репозитории Art Radar откройте **Settings → Secrets and variables → Actions → Secrets → New repository secret**. Сохраните ключ как `JOURNAL_YOUTUBE_API_KEY`. [Настройка секретов GitHub Actions](https://docs.github.com/en/actions/how-tos/write-workflows/choose-what-workflows-do/use-secrets)
4. В **Actions → Журнал Art Radar → Run workflow** выберите `check_platforms`. Строка `YouTube · channels.list · публичный канал подтверждён` показывает, что ключ работает. Затем запустите `preview` и откройте `audit.html` из артефакта. В отчёте видны результаты авторских лент, дополнительных запросов и подтверждённый хронометраж. [Ручной запуск GitHub Actions](https://docs.github.com/en/actions/how-tos/manage-workflow-runs/manually-run-a-workflow)
5. Следите за расходом в Google Cloud Console на странице **YouTube Data API v3 → Quotas**. На 19 ноября 2026 года Google указывает базовый лимит 100 вызовов `search.list` в сутки и 10 000 единиц в сутки для прочих методов общего пула. Проверяйте фактические лимиты своего проекта. Art Radar отдаёт приоритет Atom и использует максимум четыре запроса `search.list` за один сбор. Вызовы `videos.list` используют пачки до 50 ID. [Квоты Google](https://developers.google.com/youtube/data/guides/quota_and_compliance_audits) · [Метаданные видео](https://developers.google.com/youtube/v3/docs/videos/list)

## VK Видео

1. Войдите в кабинет VK ID для бизнеса и создайте приложение для Art Radar или откройте своё существующее приложение. Выберите тот тип приложения, которому VK предоставляет доступ к методам VK API для вашего сценария. [Кабинет VK ID](https://id.vk.com/business/go) · [Официальный SDK VK ID](https://github.com/VKCOM/vkid-web-sdk)
2. В настройках приложения настройте разрешённый OAuth-переход и запросите у VK доступ к `video.get` с пользовательским токеном и разрешением `video`. Авторизуйте приложение своим аккаунтом по официальному сценарию OAuth, доступному для этого приложения. В некоторых конфигурациях авторизация VK ID выдаёт токен для входа и профиля. Если кабинет не даёт право `video`, запросите его у поддержки VK для этого приложения. [Тип токена для `video.get` в схеме VK](https://github.com/VKCOM/vk-api-schema/blob/master/video/methods.json) · [Авторизация VK ID](https://id.vk.ru/about/business/go/docs/ru/vkid/latest/vk-id/connection/start-integration/auth-without-sdk/auth-without-sdk-web)
3. Сохраните пользовательский `access_token` в GitHub как `JOURNAL_VK_ACCESS_TOKEN`. При истечении срока действия обновите значение секрета через подтверждённый способ авторизации. `APP_ID` и ключ приложения для запуска журнала не требуются. [Настройка секретов GitHub Actions](https://docs.github.com/en/actions/how-tos/write-workflows/choose-what-workflows-do/use-secrets)
4. Запустите `check_platforms`. Успешный вызов выводит `VK · video.get · ответ получен` и число открытых роликов, найденных проверочным запросом. Проверка читает один ролик с настроенного публичного канала. Сверьте подключённые каналы в отчёте `preview`. Для страниц с псевдонимом используется `utils.resolveScreenName`, для известных числовых ID — сразу `video.get`.
5. Контролируйте статус в `audit.html`. Код `5` означает проблему с авторизацией, `7` — с правами, `6` — с частотой запросов. Art Radar читает одну страницу до 25 записей на канал, выполняет обращения к VK последовательно с паузой и при ошибке использует остальные источники выпуска. [Официальные коды ошибок VK](https://github.com/VKCOM/vk-api-schema/blob/master/errors.json)

Для локальной диагностики с ключами, уже заданными в окружении, выполните `python -m radar.telegram_journal check-platforms`. Значения ключей команда не выводит. Платные подписки и API для этой схемы не требуются.
